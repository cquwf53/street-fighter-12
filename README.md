# 十二人街霸 · Classic UI v2

Play: https://cquwf53.github.io/street-fighter-12/?v=2

A single-file, offline-capable arcade tribute with a classic 4:3 presentation, world-map selection, twelve character portraits, pixel HUD, VS transitions, Ryu/Ken sprite animations, local two-player mode and CPU opponents.

Press Enter to open selection and Enter again to fight. Player 1: WASD + J/K/L/I/U. Player 2: arrows + 1/2/3/5/4. Escape pauses.

This release mixes sourced pixel artwork and procedural graphics. Ten fighters' combat visuals remain procedural, and the game is not a frame-perfect original port. See THIRD-PARTY-NOTICES.md for artwork sources and acknowledgements.
