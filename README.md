# 十二人街霸 · World Warrior

Play: https://cquwf53.github.io/street-fighter-12/

An offline-capable, single-HTML arcade fighting tribute with 12 fighters, three stages, local two-player mode and CPU opponents.

Controls: Player 1 uses WASD + J/K/L/I/U; Player 2 uses arrow keys + 1/2/3/5/4. Escape pauses. In-game command list includes gamepad controls.

All visuals are procedurally drawn and sounds synthesized. This is an independent tribute, not an original ROM or frame-perfect port. Character and game names belong to their respective owners.
